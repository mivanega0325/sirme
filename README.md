# Sistema de Registro y Monitoreo de Empleados ( SIRME )

El sistema propuesto SIRME tiene como objetivo facilitar el registro, seguimiento y análisis de las horas trabajadas por los empleados. Este sistema proporcionará una plataforma eficiente y accesible para que los empleados ingresen sus horas, lo que permitirá a los gerentes de proyectos tener una visión clara de la dedicación de cada miembro del equipo, ayudando en la toma de decisiones sobre la asignación de recursos y la gestión de tiempos.

## Descripción

La implementación de un sistema de registro de horas para empleados es fundamental para mejorar la eficiencia operativa, optimizar la asignación de recursos y garantizar la rentabilidad de los proyectos. Este sistema permitirá recopilar datos precisos sobre la dedicación de cada empleado, facilitando la identificación de cuellos de botella, la medición del desempeño y la mejora en la gestión del tiempo.
El sistema debe enfocarse en las funcionalidades esenciales para registrar, gestionar y visualizar el tiempo trabajado por los empleados, asegurando una experiencia básica pero 
funcional.

## Instalación

1. Clonar el repositorio

```bash
git clone https://github.com/mivanega0325/sirme.git
```

2. Descargar el archivo por Download ZIP


## Uso

Para utilizar el sistema se puede realizar de la siguiente manera:

1. Abrir el VsCode y ejecutar el Live Server para HTML (para cada uno de los archivos)

    Aquí solo se podrán visualizar las pantallas iniciales del Proyecto SIRME, estos botones aún NO son funcionales, pero se puede ver un avance de dicha maquetación y diseño.

3. Ejecutar el código JavaScript

    Desde la terminal ejecutar el comando "node empleados.js" para ver el ejercicio del CRUD funcional correspondiente a la Evidencia "Codificación de módulos del software según requerimientos del proyecto GA7-220501096-AA2-EV01". Dicho crud corresponde al avance requerido, el cual se seguirá trabajando durante el transcurso de la semana con sus mejoras.
